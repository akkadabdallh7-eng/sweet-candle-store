# SWEET CANDLE — متجر مع لوحة إدارة

هذه النسخة تحافظ على واجهة المتجر الحالية، وتضيف لوحة إدارة حقيقية عبر Netlify Functions + Netlify Blobs.

## قبل النشر على Netlify

في Netlify > Project configuration > Environment variables أضف:

- `ADMIN_USERNAME` = اسم مستخدم الإدارة
- `ADMIN_PASSWORD` = كلمة مرور قوية
- `ADMIN_SECRET` = سلسلة عشوائية طويلة وسرية

لا تضع هذه القيم داخل `index.html`.

## الاستخدام

1. ارفع مجلد المشروع إلى Netlify.
2. بعد نجاح النشر افتح الموقع.
3. اضغط زر `T` الصغير أسفل الصفحة.
4. سجّل الدخول.
5. أضف الاسم والسعر والكمية والألوان والصورة والوصف.
6. اضغط «نشر المنتج».
7. المنتج المنشور يُحفظ في Netlify Blobs ويظهر للزوار من أجهزتهم المختلفة.

## ملاحظة عن المخزون

الكمية هنا هي مخزون المنتج الظاهر في المتجر. الطلبات الحالية تُرسل عبر واتساب، لذلك لا يتم إنقاص المخزون تلقائياً بعد إرسال واتساب. يمكن إضافة نظام طلبات مركزي لاحقاً إذا رغبت.
